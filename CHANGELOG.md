# История изменений

## 1.0.0

Первая версия для Windows.

- Клиент на Go и Wails вместо Android-приложения. Транспорт перенесён из
  `go_client` и работает внутри процесса программы.
- Системный VPN через Wintun с маршрутами, DNS и защитой от утечек.
- Прокси SOCKS5 и HTTP CONNECT без прав администратора.
- Маршрутизация по IPv4, подсетям, диапазонам, доменам и URL.
- Окно для ручного прохождения капчи VK.
- Установка, обновление и администрирование `wdtt-server` по SSH.
- Сервер вынесен в каталог `server/`, совместим с серверами, установленными
  Android-версией WDTT Plus (v20).

История Android-версии — в репозитории
[WDTT Plus](https://github.com/Ivan4537/WDTT-Plus/blob/main/CHANGELOG.md).
