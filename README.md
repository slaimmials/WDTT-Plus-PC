# WDTT Plus для Windows

WDTT Plus поднимает WireGuard-туннель до вашего сервера через TURN-серверы
VK. Для провайдера трафик выглядит как зашифрованный медиапоток видеозвонка VK.

Это ПК-версия форка [WDTT Plus](https://github.com/Ivan4537/WDTT-Plus), который
основан на [proxy-turn-vk-android](https://github.com/amurcanov/proxy-turn-vk-android).

## Как это работает

```text
Windows ──DTLS──▶ TURN-сервер VK ──UDP──▶ ваш VPS (wdtt-server) ──▶ интернет
```

1. Программа анонимно заходит в звонок VK по его ссылке и получает временные
   учётные данные TURN-сервера.
2. Через TURN-сервер устанавливается пул DTLS-каналов до `wdtt-server` на
   вашем VPS. Пакеты дополнительно шифруются ключом из пароля подключения.
3. Поверх этих каналов работает обычный WireGuard. Сервер выдаёт клиенту
   конфигурацию сам, импортировать `.conf` не нужно.

## Возможности

- **VPN** — системный адаптер Wintun, весь трафик Windows идёт через туннель.
  В режиме «весь трафик» включается защита от утечек: соединения мимо
  туннеля и DNS-запросы к посторонним серверам блокируются.
- **Прокси без VPN** — SOCKS5 и/или HTTP CONNECT на локальном порту, без прав
  администратора. Прокси можно открыть для локальной сети с логином и паролем.
- **Маршруты** — весь трафик, всё кроме списка или только список. В списках
  IPv4-адреса, подсети, диапазоны, домены и URL.
- **Профили** — несколько подключений, импорт и экспорт по ссылке `wdtt://`.
  Ссылки `wdtt://` из браузера открываются в программе.
- **Капча VK** — сначала решается автоматически; если не получилось,
  открывается окно, где её проходят вручную.
- **Свой сервер** — установка и обновление `wdtt-server` на VPS по SSH,
  управление клиентами, сроками доступа, настройками и резервными копиями.

## Требования

- Windows 10 или 11, x64.
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
  (в Windows 11 уже установлен).
- Права администратора — только для режима VPN.
- Для своего сервера: VPS с Linux (Debian 11+, Ubuntu 20.04+, CentOS/RHEL,
  Fedora, AlmaLinux, Rocky), x86_64 или ARM64, systemd и SSH-доступ с root или
  sudo.

## Быстрый старт

### Если у вас есть ссылка `wdtt://`

1. Скачайте `WDTT-Plus-<версия>-windows-amd64.exe` со страницы
   [выпусков](../../releases).
2. **Подключение → По ссылке**, вставьте ссылку.
3. Нажмите кнопку подключения. Для режима VPN программа предложит
   перезапуститься от имени администратора.

### Если нужен свой сервер

1. **Серверы → Добавить сервер**: адрес VPS, SSH-логин и пароль или ключ,
   главный пароль администратора (придумайте сами).
2. **Установка → Установить или обновить**. Программа поставит пакеты,
   `wdtt-server`, службу systemd и откроет порты `56000/udp` и `56001/udp`.
3. **Клиенты → Новый клиент**: укажите VK-хеш. Ссылка подключения
   скопируется в буфер обмена — добавьте её как профиль у себя или отправьте
   другому человеку.

Если не хотите давать программе SSH-доступ, установите сервер вручную через
[`server-installer`](server-installer/README.md).

## VK-хеш

VK-хеш — это код из ссылки на звонок: `https://vk.com/call/join/<хеш>`.

1. Создайте групповой звонок в VK (например, в пустом сообществе).
2. Скопируйте ссылку-приглашение и вставьте её в поле VK-хешей профиля —
   программа сама вырежет хеш. Можно указать несколько хешей, по одному в
   строке: каналы распределятся между звонками.
3. Выходя из звонка, выбирайте **«Просто завершить»**, а не **«Завершить для
   всех»**, иначе ссылка перестанет работать.

Кнопка **Проверить хеши** в профиле покажет, какие звонки рабочие.

## Режимы и маршруты

| Режим   | Что делает                                    | Права администратора |
|---------|-----------------------------------------------|----------------------|
| VPN     | Сетевой адаптер для всей системы              | нужны                |
| Прокси  | SOCKS5 и HTTP CONNECT на одном порту          | не нужны             |
| SOCKS5  | Только SOCKS5 (TCP и UDP)                     | не нужны             |
| HTTP    | Только HTTP CONNECT (TCP)                     | не нужны             |

Маршруты применяются к режиму VPN. Домены превращаются в IP-адреса в момент
подключения. Выбирать отдельные приложения, как в Android-версии, в Windows
нельзя: для этого нужен собственный драйвер.

## Данные программы

Настройки, профили и пароли хранятся в `%APPDATA%\WDTT Plus\settings.dat` и
зашифрованы ключом вашей учётной записи Windows (DPAPI). Там же лежит журнал
`wdtt.log`. Ключ SSH-сервера запоминается при первом подключении; если он
изменится, программа откажется подключаться.

## Сборка

Нужны Go 1.26+, Node.js 22+ и Wails CLI:

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.0
client/scripts/build.sh
```

Скрипт работает в Git Bash, WSL, Linux и macOS. Он собирает `wdtt-server` для
встроенного деплоя, скачивает Wintun и собирает
`dist/WDTT-Plus-<версия>-windows-amd64.exe`. Тот же скрипт выполняется в GitHub
Actions для каждого тега `v*`.

Тесты:

```bash
(cd server && go test ./...)
(cd client/frontend && npm ci && npm run check && npm run build)
(cd client && go test ./...)
```

## Структура репозитория

```text
client/                  ПК-клиент (Go + Wails)
  internal/core/         транспорт: VK, TURN, DTLS, прокси
  internal/tunnel/       адаптер Wintun, маршруты, DNS, защита от утечек
  internal/routing/      правила маршрутизации
  internal/profile/      профили, ссылки wdtt://, хранение настроек
  internal/sshx/         SSH-клиент
  internal/admin/        управление сервером
  internal/deploy/       установка сервера (deploy.sh)
  internal/captcha/      окно капчи VK
  frontend/              интерфейс (Svelte)
server/                  wdtt-server
pathprobe/               общий модуль проверки путей для клиента и сервера
server-installer/        ручной установщик сервера
warp-interface-manager/  выборочный выход через Cloudflare WARP на сервере
```
